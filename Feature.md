# Main Header Bar Implementation

## Task

Create a **main header bar** that follows the design shown in the reference image. The header must include the page title, user profile section, and logout functionality.

## Requirements

### 1. Header Layout

* The left side must display a **page title**.
* The right side must include:

  * A **user profile icon**
  * The **user’s name**
  * A **logout icon/button**

### 2. Logout Behavior

* When the logout icon is clicked:

  * Show a **confirmation alert** asking if the user wants to log out.
  * If the user confirms, redirect to:

    * `http://127.0.0.1:5500/login.html`

### 3. Page Title Rotation

* Every time the page is reloaded, the page title should automatically rotate between:

  1. **Services**
  2. **Employee Management**
  3. **Service Overview**
* The sequence must continue cyclically on each reload.

### 4. Hover Effect

* When hovering over the **logout icon**, its color should change to:

  * `#2A00B2`

### 5. Build Requirements

* Build **from scratch** using HTML, CSS, and JavaScript.
* Must match the exact style shown in the reference image.
* Deliver as a **single standalone HTML file** containing all CSS and JavaScript inline.
